### Huckleberry

[Huckleberry](https://huckleberryservices.com/) is FSM's platform for **utility data, building analytics, and field operations** — bringing utility billing, equipment data, and site surveys into one place for energy and facilities teams.

I own the full rollout, modernization, and go-to-market. Day-to-day that looks like:

- Shipping product features and keeping production running while modernizing the front end toward React and TypeScript
- Automating utility account and interval-data ingest so portfolios stay current without manual busywork
- Connecting building management systems (**Niagara**, **SkySpark**) for live equipment readings, dashboards, and analytics
- Turning field surveys and site audits into structured data that feeds analysis and ongoing facilities management
- Aligning the product with real HVAC controls and lighting upgrade work so software matches how buildings actually operate
